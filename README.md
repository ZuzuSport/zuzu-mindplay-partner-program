# Zuzu MindPlay Partner Program

> **Landing page and application form for the Zuzu MindPlay Partner Program.**  
> For pediatric therapists, OTs, kids' movement coaches, youth sports coaches, child-development professionals, clinics, parent creators, and community leaders.

---

## Overview

This repository contains the complete front-end for the Zuzu MindPlay Partner Program landing page, hosted at **partners.zuzumindplay.com**.

The page enables professionals and creators who work with children and families to apply to become Zuzu MindPlay partners — earning revenue share when the families they refer become paid subscribers.

---

## Files

| File | Description |
|------|-------------|
| `index.html` | Full landing page with all sections and the partner application form |
| `styles.css` | Mobile-first CSS — design system, layout, components |
| `app.js` | Form validation, partner code enforcement, submission handling |

---

## Page Sections

1. **Hero** — Headline, subheadline, primary & secondary CTAs
2. **Who It's For** — 6 partner audience cards
3. **Why Families Use It** — 6 benefit highlights
4. **How It Works** — 4-step partner flow
5. **Partner Rewards** — Standard (10%), Professional (15%), Strategic (20%) tiers
6. **Compliance Note** — Safe-use commitment box
7. **Application Form** — Full multi-fieldset form with validation
8. **FAQ** — 7 common questions
9. **Footer**

---

## Application Form Fields

- Basic information (name, email, phone, location, business, social profiles, title)
- Partner type (10 checkboxes)
- Professional background
- Audience & reach (size selector, channels)
- Program fit (usage intent, goals)
- Preferred partner code (uppercase + numbers, 4–15 chars)
- Compliance agreement checkbox

---

## Compliance

Zuzu MindPlay is a family-friendly brain-body movement app. It is **not** a medical treatment, therapy replacement, or diagnostic tool. All partner-facing copy uses approved language:

- ✅ supports focus
- ✅ encourages movement
- ✅ builds confidence
- ✅ active screen time
- ✅ brain-body play
- ✅ at-home family activity

## Getting Started

Clone the repo and open `index.html` in your browser — no build step required.

```bash
git clone https://github.com/ZuzuSport/zuzu-mindplay-partner-program.git
cd zuzu-mindplay-partner-program
open index.html
```

For production, point your web server's document root at this folder or deploy via GitHub Pages, Netlify, or Vercel.
